# 💈 Telegram-бот для записи на услуги (Барбершоп)

Демонстрационный проект: функциональный **Telegram-бот для онлайн-записи клиентов** с выбором услуги, мастера, свободной даты и времени.

Бот автоматически проверяет занятые слоты, хранит данные в базе SQLite и отправляет уведомления администратору.

## Возможности

- **Пошаговый мастер записи:** интерактивный выбор услуги, мастера, даты и доступного времени через Inline-клавиатуры;
- **Защита от накладок (Double-booking):** проверка занятости мастеров в базе данных в режиме реального времени;
- **Фильтрация времени:** автоматическое скрытие прошедших часов для записи «на сегодня»;
- **Личный кабинет клиента («Мои записи»):** просмотр предстоящих визитов и возможность отменить запись;
- **Уведомления администратору:** мгновенные оповещения в Telegram при создании новых бронирований;
- **Раздел информации:** удобное отображение прайс-листа, списка мастеров и контактов.

## База данных и хранение данных

- используется легкая локальная база данных **SQLite** (`barbershop.db`);
- структура базы создаётся автоматически при первом запуске;
- хранятся только данные о бронированиях (ID пользователя, имя, мастер, услуга, дата и время).

## Стек

- Python 3.10+

## Установка и запуск

1. **Получите токен Telegram-бота**: напишите [@BotFather](https://t.me/BotFather), отправьте команду `/newbot`.
2. **Узнайте свой Telegram ID** (для получения уведомлений): напишите [@userinfobot](https://t.me/userinfobot).
3. **Установите зависимости** (рекомендуется виртуальное окружение):

   ```bash
   python -m venv venv
   source venv/bin/activate        # Windows: venv\Scripts\activate
   pip install -r requirements.txt
   ```

4. **Создайте файл `.env`** на основе примера и впишите данные:

   ```bash
   cp .env.example .env            # Windows: copy .env.example .env
   ```

   ```env
   telegram_bot_token_here=ваш_токен_бота
   ADMIN_ID=ваш_telegram_id
   ```

5. **Запустите бота**:

   ```bash
   python main_2.py
   ```

6. Откройте бота в Telegram, отправьте `/start` или `/menu` для перехода к записи.

## Настройка

| Что | Где | Описание |
|---|---|---|
| Список услуг | словарь `SERVICES` в `main_2.py` | Название, цена в ₸/₽ и длительность |
| Список мастеров | словарь `MASTERS` в `main_2.py` | Имена и специализация мастеров |
| Временные слоты | список `TIME_SLOTS` в `main_2.py` | Доступные часы для записи (например, `["10:00", "11:00"]`) |
| Глубина записи | переменная `DAYS_AHEAD` | На сколько дней вперед разрешена запись (по умолчанию `7`) |
| Контакты заведения | константы `SHOP_NAME`, `ADDRESS`, `PHONE` | Название, адрес и контакты для меню |

## Возможные проблемы

- **Запись не сохраняется / ошибка базы данных:** убедитесь, что у скрипта есть права на запись файлов в директорию проекта для создания `barbershop.db`.
- **Администратор не получает уведомления:** проверьте, что в `.env` указан верный числовой ID пользователя (не никнейм через `@`), и что вы сами запустили бота со своего аккаунта.
- **«Это время только что заняли»:** сработала защита от одновременной записи нескольких пользователей на один и тот же слот.

## Безопасность

Не публикуйте файл `.env` и файл базы данных `barbershop.db` в публичном доступе. Добавьте `.env` и `*.db` в файл `.gitignore`.
